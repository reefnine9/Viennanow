# 사진 라이선스 목록

선택한 7개 파일은 Wikimedia Commons의 각 사진별 저작권 안내를 검토한 사진입니다. 실제 이미지는 외부 CDN에서 온라인으로 표시됩니다. 이 프로젝트 패키지에는 사진 바이너리가 포함되어 있지 않습니다. 배포 전에는 적법한 방법으로 내려받아 저장하고 출처/저작권 고지를 유지하는 것을 권장합니다. 사진이 로딩되지 않아도 앱 버튼과 내용은 사용 가능합니다.

`../photo_manifest.json`에 저작자, 라이선스, 원본 페이지, 뷰포트 표시 방식이 들어 있습니다. CC BY-SA는 출처·라이선스 링크·변경표시 등 조건 준수가 필요합니다.
